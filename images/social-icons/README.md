# Social icon provenance

Facebook, Instagram, YouTube and TikTok SVGs are from the Simple Icons project,
downloaded 2026-09-14 from `https://github.com/simple-icons/simple-icons/tree/develop/icons`.
Their original SVG geometry is retained. The included `LICENSE.md` contains the
project's CC0 license. Brand trademarks remain their respective owners' property;
these are recognizable third-party icon renditions, not a claim of brand approval.

The footer displays them as white glyphs on platform-color wells using CSS.
Future LinkedIn support uses a small text monogram. No platform is rendered unless
a verified HTTPS profile URL is configured in `site-config.js`.
