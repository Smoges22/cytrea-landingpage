# Cytrea typography

One self-hosted Inter variable font supplies body and display typography. The site
previously named Inter without providing it, so rendering depended on system fonts.

- Source: https://fonts.google.com/specimen/Inter
- Author's project: https://rsms.me/inter/
- Original WOFF2: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Downloaded: 2026-09-14; Google Fonts distribution v20, Latin variable weights 100–900.
- Size: 48,256 bytes. SHA-256: `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62`.
- License: SIL Open Font License 1.1, included in `OFL.txt`.

Original font bytes are unmodified. `font-display: swap` preserves visible content
while loading. A single same-origin preload avoids runtime third-party font calls.
Unsupported characters use the system sans-serif fallback; no second webfont is loaded.
