# Cytrea typography

One self-hosted Plus Jakarta Sans variable font supplies body and display typography.
Selected after comparing Inter, Manrope, and Plus Jakarta Sans in the warm-premium pass.

- Source: https://fonts.google.com/specimen/Plus+Jakarta+Sans
- Author's project: https://github.com/tokotype/PlusJakartaSans
- Original WOFF2: https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yw.woff2
- Downloaded: 2026-09-14; Google Fonts distribution v12, Latin variable weights 400–800.
- Size: 27,348 bytes. SHA-256: `153fc85b70298beeb1d61a5f723331649e7f23bb77302a66e61cb3e2fbdb5e79`.
- License: SIL Open Font License 1.1, included in `PlusJakartaSans-OFL.txt`.

Original font bytes are unmodified. `font-display: swap` preserves visible content
while loading. A single same-origin preload avoids runtime third-party font calls.
Unsupported characters use the system sans-serif fallback; no second webfont is loaded.
